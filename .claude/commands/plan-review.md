# plan-review — Codex Gate レビュー

実装計画またはコード変更を、別の視点でレビューするゲート。

## 使い方

1. Plan mode で計画を作成
2. このコマンドを実行して、計画の致命的な問題をチェック

## チェックリスト

以下の観点で計画をレビューしてください:

### セキュリティ
- [ ] 新しいエンドポイントに認証は必要か？
- [ ] シークレット/APIキーの取り扱いは安全か？
- [ ] 入力バリデーションは適切か？

### 設計
- [ ] 既存のパターンに沿っているか？
- [ ] Fail-closed 原則に従っているか？
- [ ] 500行を超えるファイルはないか？

### テスト
- [ ] 新機能に対応するテストが計画されているか？
- [ ] エッジケース（None, 空リスト, エラー）は考慮されているか？
- [ ] モック対象は適切か？

### 影響範囲
- [ ] 変更は最小スコープに限定されているか？
- [ ] 既存テストへの影響はあるか？
- [ ] breaking change はないか？

致命的な問題のみ指摘してください。瑣末な点は無視。
