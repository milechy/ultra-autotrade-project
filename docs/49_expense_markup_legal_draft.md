## 0. 目的

v10 fee model における経費マークアップ機能 (デフォルトOFF) のユーザー説明と
利用規約条文ドラフトを定義する。

本ドキュメントはバックエンドロジック (F-9) 完了時点のドラフトであり、
admin UI (F-12)・月次明細表示 (F-11)・法務レビュー (F-15) が完了するまで
ユーザー向けに公開しない。

## 1. 機能概要

### 1.1 デフォルト動作 (Phase 1〜)

| 設定 | 値 | 説明 |
|---|---|---|
| `expense_markup_enabled` | `false` | マークアップ無効 (デフォルト) |
| `expense_markup_rate` | `0` | マークアップ率 (0〜1.0) |
| ユーザーへの請求額 | 実費 × 1.0 | 実費のみ差し引き |

### 1.2 マークアップ ON 時の動作

| 設定 | 例 | 説明 |
|---|---|---|
| `expense_markup_enabled` | `true` | マークアップ有効 |
| `expense_markup_rate` | `0.10` | 10% マークアップ |
| ユーザーへの請求額 | 実費 × 1.10 | 加算分は UATa 収入 |

月次手数料計算における経費処理フロー:

```
Step 0 (F-9):
  raw_expense_jpy    = 実際に発生した取引手数料・ガス代等
  effective_expense  = round_down(raw_expense × (1 + markup_rate))
  markup_amount      = effective_expense - raw_expense

Step 1:
  net_profit = gross_profit - effective_expense
```

### 1.3 月次明細での分離表示

ユーザーの透明性確保のため、月次明細に以下を分離表示する (F-11 で実装):

| フィールド | 説明 |
|---|---|
| `raw_expense_jpy` | 実費 (マークアップ前) |
| `expense_markup_amount_jpy` | マークアップ加算分 |
| `expense_jpy` | 合計経費 (実費 + 加算分) |

## 2. ユーザーへの透明性

### 2.1 必須開示事項

1. 月次明細に `raw_expense_jpy` (実費) と `expense_markup_amount_jpy` (加算分) を分離表示
2. 設定変更 (OFF → ON または rate 変更) 時は **30日前にメール + ダッシュボード通知**
3. 規約変更同意フロー実装 (F-13 / F-15 で実施)

### 2.2 OFF前提でのテスター運用

- 山本さん含む Phase 1 テスターは `expense_markup_enabled=false` で運用
- 法人設立前の本番リリース時に ON を検討
- ON にする場合は必ず森先生レビュー後に実施

## 3. 利用規約条文ドラフト

> 以下は叩き台。森先生のレビューを経て確定する。条番号は仮番。

### 第○条 (経費の請求)

1. 当社は、お客様による本サービスの利用に伴い当社が実際に負担した
   取引手数料、ネットワーク手数料、ガス代等 (以下「実費」) を、
   お客様の月次手数料計算において控除します。

2. 当社は、実費に対して一定の事務手数料率 (以下「マークアップ率」) を
   乗じた金額を実費とすることがあります。マークアップ率を適用する場合、
   当社はその旨をあらかじめ電子メールおよび本サービス内通知により
   30日前までにお客様に通知します。

3. マークアップ率の適用および変更は、お客様の事前同意を要します。
   同意がない場合、当社は当該お客様についてマークアップ率を 0% として
   取り扱います。

4. 月次手数料明細において、当社は実費とマークアップ加算額を分離して
   表示します。

### 第○条 (UATa 収入の使途)

本規約に基づき発生する手数料、サブスクリプション、月次運用上限超過分、
ならびに前条第2項のマークアップ加算額は、当社の事業収入として処理されます。

## 4. 法務確認事項 (森先生)

- [ ] マークアップ率上限の規制有無 (景表法 / 消費者契約法)
- [ ] BVI法人格と日本居住ユーザー間の課税関係 (消費税・源泉徴収)
- [ ] マークアップ加算分の消費税扱い (課税売上 or 非課税)
- [ ] 30日前通知期間の妥当性 (一般的な利用規約変更通知期間との比較)
- [ ] 同意フローの法的拘束力 (クリックラップ vs サインアップ時同意)
