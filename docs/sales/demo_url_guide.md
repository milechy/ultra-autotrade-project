## アクセス URL

| 環境 | URL |
|------|-----|

| 本番環境（参考） | https://app.ultra-auto-trade.com |

> デモ環境は Cloudflare Pages にホストされたフロントエンド専用の静的サイトです。
> 実際の API 呼び出しはなく、すべてのデータはサンプルです。

---

## デモ環境の特徴 (営業展開時の制約 — 必ず把握)

- **ログイン不要**: URL を開くだけで **partner 視点** で全画面を閲覧可能 (内部で自動的にデモ用 partner ユーザーとして扱われます)
- **データはサンプル**: 本番の実データは一切表示されません (すべて架空、固定値の sample data)
- **リアルタイム更新なし**: 静的 (pre-rendered) 配信のため、画面のチャート / 数値は固定。「再読み込みで値が変わる」ことはありません
- **日本語のみ**: 国際化 (英語) はデモでは無効。`Accept-Language: en` を送っても日本語表示
- **招待リンクは機能しない**: `/r/<code>` (例: `/r/demo-2026`) はデモでは存在しません (静的サイトのため dynamic route 削除済)。招待リンクを見せたい場合は **`/auth/register?ref=xxx`** を直接開いてください
- **本番への影響なし**: デモ操作 (承認ボタン / 設定変更等) は本番 backend / DB に届きません
- **デモバナー表示**: 画面上部に黄色いバナーが表示され、デモ環境であることを示します

## よくある質問 (FAQ)

### Q: これは本物のデータですか?

**A:** いいえ。デモ環境のすべてのデータはサンプル (架空の固定値) です。画面上部の黄色いバナー「⚠️ DEMO 環境」で識別できます。再読み込みしても値は変わりません。

### Q: ログイン情報は必要ですか?

**A:** **不要** です。URL を開くだけで自動的に partner 視点で全画面を閲覧可能になります。営業先に「テスト用 ID / パスワード」を渡す必要はありません。

### Q: 招待リンクを開いたら 404 になりました

**A:** デモ環境では `/r/<code>` 招待リンクは **動作しません** (静的サイトのため dynamic route 削除済)。代替で `/auth/register?ref=demo-2026` 等を直接お試しください。本番環境では正常に動作します。

### Q: 英語表示にできますか?

**A:** デモ環境では **日本語のみ** です。本番環境では英語切替可能です。

### Q: 数値や数字をリアルタイムで動かして見せたいです

**A:** デモ環境は静的配信のため、画面値は固定です。リアルタイム動作は本番環境または staging 環境で別途デモご手配します。

### Q: 本番環境と何が違いますか?

**A:** デモ環境では:
- API呼び出しが行われない（モックデータを返す）
- ウォレット署名・承認操作が本番に届かない
- 実際の資金移動は一切発生しない
- リアルタイム更新がない (静的 prerender)
- 国際化 (英語) 無効
- `/r/<code>` 招待リンクが機能しない

本番環境では Aave V3 (Base) に実際の USDC を運用します。

### Q: 本番環境のアカウント作成方法は?

**A:** 本番環境は招待制です。パートナー様の招待コード経由で登録、または小林さん (代表) へ直接お問い合わせください。

### Q: Health Factor とは?

**A:** Aave での担保比率の指標です。1.6 未満になると自動緊急停止が発動します。デモでは 2.05 で安全に運用中です。

### Q: AIはどのモデルを使用していますか?

**A:** Claude Sonnet 4.6（一次判定）+ GPT-4o（二次検証）のダブルチェック体制です。両者が合意した場合のみ BUY/SELL を推奨します。

### Q: パートナー手数料はどう計算されますか?

**A:** デモ画面の「手数料体系」(`/users/fee-schedule`) に記載の通り、運用ティアに応じて 0.75%〜2.5% のレンジで毎月決定されます (パフォーマンス・取引頻度連動)。詳細は `docs/45_fee_model_v10_migration_plan.md` を参照。
