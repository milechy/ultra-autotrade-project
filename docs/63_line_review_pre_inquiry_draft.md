## 照会文（日本語・コピペ用）

件名: LINEミニアプリ認証可否のご相談（非カストディアル型 暗号資産運用支援アプリ）

本文:

弊社が提供予定の LINE ミニアプリについて、認証審査の可否をご相談いたします。

**サービス概要**
- 名称: Ultra AutoTrade（UAT）
- 種別: 非カストディアル型のデジタル資産（暗号資産・USDC）運用支援ツール
- 仕組み: 利用者は自分自身が管理するウォレット（Privy 提供のウォレット基盤）を接続し、
  資産は常に利用者本人の管理下にあります。**運営は利用者の資産・秘密鍵を一切預かりません
  （非カストディアル）**。AI が市場を分析して取引を「提案」し、**利用者が一件ずつ承認した
  ものだけ**が、利用者自身のウォレットで Base チェーン上の DeFi（Aave 等）に対して実行されます。
- **一任運用（AI が自動で売買を執行するモード）は提供しません**（UI 上も非表示）。
  あくまで利用者の都度承認が必要なツールです。
- **利用料金は現在無料**です（将来導入する場合は事前にサービス内で明示し、利用者の同意を
  得たうえで適用します）。

**運営体制**
- 運営者: ASSISTONE Sdn. Bhd.（マレーシア法人）
- 日本国内の運営者・問い合わせ窓口: YMO Yield Media Online
- 利用規約・プライバシーポリシー・特定商取引法に基づく表示をアプリ内に整備済み。

**ご相談事項**
1. 上記のような「非カストディアル型・利用者都度承認・現在無料」の暗号資産運用支援ミニアプリは、
   LINE ミニアプリの認証審査の対象として申請可能でしょうか。
2. 申請にあたり、暗号資産・DeFi を扱うことに起因して追加で必要となる要件（法令適合の証明、
   本人確認、年齢確認、特定の表示等）がございましたらご教示ください。
3. 申請が難しい場合、どのような設計変更・条件を満たせば認証可能となるか、可能な範囲で
   ご示唆いただけますと幸いです。

お手数をおかけしますが、ご確認のほどよろしくお願いいたします。

## 照会前に揃えておくもの（添付/参照用）
- 審査用 LIFF（staging-v4 配信版）の URL とテスト手順（取引系のためテストシナリオ要求の可能性）
- 運営者情報（ASSISTONE 登記情報 / YMO 事業者情報・住所・連絡先 info@yieldmediaonline.com）
- 利用規約・プライバシーポリシー・特定商取引法に基づく表示の各 URL

## 回答パターン別の次アクション
- **「申請可」回答** → 本申請へ（残りの審査要件＝事業者名一致/テストシナリオ/UI要件 を仕上げる）
- **「条件付き可」回答** → 提示条件を満たす設計変更（例: KYC 追加、特定表示）を実施してから申請
- **「不可」回答** → LINE 申請は見送り、**PWA + Privy passwordless 継続**（現 v3 本番経路）に確定。
  LINE 集客機能は諦め、開発リソースを PWA 体験へ振り向ける。
