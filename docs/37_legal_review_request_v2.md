## 付録A: サービス技術概要（森先生向け説明資料）

### Ultra AutoTradeとは

**サービスカテゴリ:** AI活用型DeFi資産運用支援サービス

**コアアーキテクチャ（非カストディアル設計）:**

```
ユーザー
  ↓ [ウォレット接続: Privy / MetaMask / WalletConnect]
  ↓ [秘密鍵はユーザーデバイス内 / Privyの場合はMPC分散管理]
Ultra AutoTrade WebApp（フロントエンド）
  ↓ [AI判定結果の提案表示]
ユーザー
  ↓ [明示的な承認ボタンタップ] ← 自動実行は一切なし
Aave V3 プールコントラクト（Arbitrum / Base）
  ↑ ユーザーのウォレットから直接トランザクション署名・送信
```

**重要な特徴:**
- ユーザーの資産は常にユーザー自身のウォレットおよびAave V3プールに保管
- 当社サーバーは資産を預かわない（カストディなし）
- AIは「提案」のみ。実行は必ずユーザーの明示的承認が必要
- 緊急停止機能あり（Health Factor < 1.6 で自動停止）

**利用するプロトコル:**
- Aave V3（Arbitrum One / Base）- 既存の独立監査済みプロトコル
- 独自のスマートコントラクトは保有しない

**現在の開発フェーズ:** テストネット試験運用中（2026-04-12時点）
