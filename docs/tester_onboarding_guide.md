# テスター向けオンボーディングガイド

**対象:** Ultra AutoTrade テスター
**環境:** Staging (テストネット)
**最終更新:** 2026-03-24

---

## 1. 事前準備

### MetaMask インストール

1. [MetaMask 公式サイト](https://metamask.io/download/) からブラウザ拡張をインストールする
2. ウォレットを新規作成、またはシードフレーズでインポートする
3. **シードフレーズは絶対に他人に共有しないこと**

> テスト用アカウントは本番資産とは別に用意することを強く推奨します。

---

## 2. Arbitrum Sepolia ネットワーク追加

MetaMask に Arbitrum Sepolia テストネットを手動追加する手順:

1. MetaMask を開き、右上のネットワーク選択をクリック
2. 「ネットワークを追加」→「ネットワークを手動で追加」を選択
3. 以下の情報を入力する:

| 項目 | 値 |
|------|-----|
| ネットワーク名 | Arbitrum Sepolia |
| 新しい RPC URL | `https://sepolia-rollup.arbitrum.io/rpc` |
| チェーン ID | `421614` |
| 通貨シンボル | `ETH` |
| ブロックエクスプローラー URL | `https://sepolia.arbiscan.io` |

4. 「保存」をクリックしてネットワークを追加する

---

## 4. テスト用 ETH 取得

テストネットでの動作確認にはテスト用 ETH (無償) が必要です。

### Arbitrum Sepolia フォーセット

- URL: https://faucet.quicknode.com/arbitrum/sepolia
- 手順:
  1. 上記 URL にアクセスする
  2. MetaMask のアドレスを貼り付ける
  3. 「Continue」をクリックして ETH を受け取る

### Base Sepolia フォーセット

- URL: https://faucet.quicknode.com/base/sepolia
- 手順:
  1. 上記 URL にアクセスする
  2. MetaMask のアドレスを貼り付ける
  3. 「Continue」をクリックして ETH を受け取る

> 取得できるまで数分かかる場合があります。テストネットの ETH に実際の価値はありません。

## 5. アカウント登録

1. 以下の URL にアクセスする:
   **https://ultra-auto-trade.com/register**

2. 登録フォームに以下を入力する:
   - メールアドレス
   - パスワード (8文字以上、英数字混在)
   - 表示名

3. 「アカウントを作成」ボタンをクリックする

4. 登録メールアドレス宛に確認メールが届くので、リンクをクリックして認証を完了する

> テスター専用の招待コードが発行されている場合は、登録フォームで入力してください。

---

## 6. ウォレット接続

1. ログイン後、以下の URL にアクセスする:
   **https://ultra-auto-trade.com/user/connect**

2. 画面の 3 ステップに従って操作する:

   **ステップ 1 — ウォレット接続**
   - 「ウォレットを接続する」ボタンをクリックする
   - MetaMask のポップアップが表示されたら「接続」を選択する

   **ステップ 2 — ネットワーク確認**
   - 接続後、ネットワークが Arbitrum Sepolia になっているか確認する
   - 異なるネットワークの場合は「Arbitrum Sepolia (testnet) に切り替える」ボタンをクリックする

   **ステップ 3 — 規約同意**
   - 「利用規約」リンクを開いて内容を確認し、チェックボックスにチェックを入れる
   - 「リスク開示文書」リンクを開いて内容を確認し、チェックボックスにチェックを入れる
   - 「運用を開始する」ボタンをクリックしてダッシュボードへ進む

---

## 7. 運用モード選択

ダッシュボードに進んだ後、運用モードを選択する:

### 完全おまかせモード
- AI が自動的に売買判断・実行を行う
- ユーザーの操作なしに運用が進む
- リスク許容度の設定のみ行う

### アクティブモード
- AI が売買提案を生成する
- ユーザーが各提案を承認 / 否認してから実行される
- より細かいコントロールが可能

> テスト時は**アクティブモード**を推奨します。AI の提案内容を確認しやすく、誤操作のリスクが低いためです。

## 8. テスト項目チェックリスト

以下の項目を順番にテストし、結果をフィードバックテンプレートに記録してください。

### AI 判定確認
- [ ] ダッシュボードに AI 判定結果 (BUY / SELL / HOLD) が表示される
- [ ] 判定の根拠・理由が確認できる
- [ ] セーフティスコアが表示される

### 提案承認テスト
- [ ] アクティブモードで AI 提案が届く
- [ ] 提案を「承認」した場合、注文が実行される
- [ ] 提案を「否認」した場合、注文がキャンセルされる

### ポートフォリオ確認
- [ ] ポートフォリオ画面に資産残高が表示される
- [ ] 取引履歴が正しく記録されている
- [ ] 損益計算が表示される

### 緊急停止テスト
- [ ] 「緊急停止」ボタンをクリックすると運用が停止される
- [ ] 停止後、新たな注文が発生しないことを確認する
- [ ] 停止解除ができることを確認する

## 9. 問題発生時の連絡先

テスト中に問題が発生した場合は、以下の方法で報告してください:

- **Slack:** `#ultra-auto-project` チャンネルに投稿する
- **フィードバックテンプレート:** `/docs/tester_feedback_template.md` を使用して報告する
- **緊急の場合:** プロジェクト担当者に直接連絡する

報告時は以下の情報を含めてください:
- 発生日時
- 使用ブラウザと OS
- MetaMask バージョン
- 接続ネットワーク
- エラーメッセージのスクリーンショット
- 再現手順
