# テスター向けオンボーディングガイド

**対象:** Ultra AutoTrade テスター（読み取り専用ビューアー）
**環境:** Base Sepolia テストネット
**最終更新:** 2026-04-21

---

## 1. はじめに

### テスターの役割

Ultra AutoTrade では、パートナー（山本さん）が配分した資金を AI が自動運用します。テスターはその運用状況を **閲覧・監視する** 役割を担います。

**テスターは「閲覧専用（viewer）」権限** です。資金操作・ウォレット接続・取引承認はパートナー側で行うため、テスター側の操作は不要です。

### Phase 1 の現状（2026-04-21 時点）

- AI 判定は 4 時間ごとに実行中
- 直近 30 日間は **HOLD 判定のみ**（BUY/SELL 未発生）
- Aave への実際の入出金はまだ発生していない
- 数値が変動しないのは **正常な状態** です

## 2. アクセス方法

### URL

**https://app.ultra-auto-trade.com**

### ログイン（Privy）

Ultra AutoTrade は **Privy** という認証基盤を使用しています。MetaMask のインストールは不要です。

1. 上記 URL にアクセスする
2. 「ウォレットを接続」または「ログイン」ボタンをクリックする
3. **メールアドレス**でログインする場合:
   - メールアドレスを入力してワンタイムコードを受け取る
   - コードを入力して認証完了
4. 初回ログイン時に **embedded wallet（埋め込みウォレット）が自動生成** される
   - アドレスは自動割り当て。テスターが手動で設定する操作はありません

### ネットワーク

| 項目 | 値 |
|------|-----|
| ネットワーク名 | Base Sepolia |
| チェーン ID | 84532 |
| 種別 | テストネット（実資産なし） |

> テスト用資産（USDC）は運営が配布します。テスターがフォーセットを使う必要はありません。

## 3. ダッシュボードの見方

ログイン後、ダッシュボード（`/user/dashboard`）で以下の情報を確認できます。

### 主要指標

| 表示項目 | 意味 |
|---------|------|
| **割当額（allocated_amount_usd）** | パートナーが自分に割り振った運用金額（ドル） |
| **現在評価額（current_value_usd）** | AI 運用後の現時点での時価評価額 |
| **PnL（損益）** | 割当額からの利益または損失額 |
| **Health Factor** | 担保借入比率の安全指標。1.6 以上で安全（Phase 1 は借入なし） |

### AI 判定の確認

- **AI 判定フィード**（`/decisions`）: 4 時間ごとに更新される最新の判定結果
- 各判定には「判定（BUY/SELL/HOLD）」「確信度」「理由」「テクニカル/マクロ/センチメント要因」が表示される
- Phase 1 現状: **HOLD が続く** = 慎重に様子見中であり、正常動作です

### 確認できる情報一覧

| ページ | 確認できる内容 |
|--------|--------------|
| ダッシュボード（/user/dashboard） | 割当額・評価額・PnL・ヘルスファクター・最新 AI 判定 |
| AI 判定フィード（/decisions） | 判定履歴・確信度・理由の詳細 |
| 取引履歴（/history） | Aave 操作履歴（現時点は空） |
| 設定（/settings） | 言語・通知設定の確認 |

## 4. 表示されるもの・されないもの

テスターの viewer 権限では、以下の操作系 UI は **表示されません**。これは意図した仕様であり、異常ではありません。

| 機能 | viewer | 備考 |
|------|--------|------|
| ダッシュボード閲覧 | ✅ 表示 | |
| AI 判定履歴閲覧 | ✅ 表示 | |
| 取引履歴閲覧 | ✅ 表示 | |
| **緊急停止ボタン** | ❌ 非表示 | admin/partner のみ |
| **運用モード切替** | ❌ 非表示 | admin/partner のみ |
| **取引提案の承認** | ❌ 非表示 | admin/partner のみ |
| **ウォレット操作** | ❌ 非表示 | パートナーが実施 |
| **設定変更** | ❌ 非表示（閲覧のみ） | リスク設定等 |

> 「なぜボタンがないのか」という問い合わせは不要です。権限設計による正常な表示です。
