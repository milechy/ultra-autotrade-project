## パートナー向けメモ

- テスターにアプリURLを共有してください: **https://app.ultra-auto-trade.com**
- テスターはメールアドレスでログインするだけです（MetaMask不要、ウォレット設定不要）
- ログイン後に embedded wallet が自動生成されます。テスター側の設定作業はありません
- テストUSDCの配布が必要な場合は、ログイン後のウォレットアドレスを Slack **#ultra-auto-project** に共有してください

## Slack #ultra-tester-feedback チャンネル設定

> **注意:** このチャンネルはまだ手動で作成が必要です。

### 手動作成手順

1. Slack ワークスペースを開く
2. 左サイドバーの「チャンネルを追加」→「チャンネルを作成」をクリック
3. チャンネル名: `ultra-tester-feedback`
4. 説明文:
   ```
   Ultra AutoTrade テスターからのバグ報告・改善要望・質問を受け付けるチャンネルです
   ```
5. プライバシー: パブリック（テスターが自由に投稿できるよう）
6. 作成後、テスターを招待する

### チャンネルで共有するピン留めメッセージ（作成後にピン留め推奨）

```
【フィードバックの書き方】

バグ報告:
- どのページで起きたか
- 何をしたら起きたか
- エラーメッセージ（あれば）
- デバイス（iPhone/Android/PC）とブラウザ

改善要望: 自由に書いてください

質問: 何でも聞いてください！
```
